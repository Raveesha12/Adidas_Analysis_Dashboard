# Adidas_Analysis_Dashboard
Adidas sales data analysis using Power bi
this dashboard conducted an in-depth Adidas Sales Analysis using Power BI, uncovering key insights into sales performance and profitability. 🔍
From this analysis, I identified:
✅ Total Sales
✅ Operating Profit
✅ Units Sold
✅ Price Per Unit
✅ Operating Margin
Additionally, I explored sales trends across various dimensions:
📅 Total Sales by Month
📍 Total Sales by State
🌍 Total Sales by Region
🛍 Total Sales by Product
🏬 Total Sales by Retailer
Power BI helped visualize and interpret this data, providing valuable business insights! 🚀📈t
